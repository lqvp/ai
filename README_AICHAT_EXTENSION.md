# AIチャット拡張機能

このドキュメントでは、藍のAIチャットモジュールに追加された拡張機能について説明します。

## 概要

AIチャットモジュールは以下の3つの主要な拡張機能を実装しています：

1. **長期記憶システム** - ユーザーとの会話内容を記憶し、文脈に応じた返答を生成
2. **パーソナライゼーション** - ユーザーの好みを学習し、応答スタイルを最適化
3. **文脈分析** - 会話の感情、トピック、重要性を分析

## 機能詳細

### 1. 長期記憶システム (MemoryManager)

ユーザーごとの会話履歴と重要な情報を保存・管理します。

#### 主な機能：
- **記憶の保存**: 重要な情報（個人情報、好み、イベントなど）を自動的に記憶
- **関連記憶の検索**: 現在の会話に関連する過去の記憶を取得
- **トピック追跡**: 会話のトピックを追跡し、話題の継続性を管理
- **記憶の整理**: 古い記憶を自動的に整理（ユーザーごとに最大1000件）

#### 記憶される情報の種類：
- 個人情報（名前、年齢、誕生日、居住地、職業など）
- 好み（好きなもの、嫌いなもの、得意なこと、苦手なこと）
- イベント（今日の出来事、明日の予定など）
- 関係性（友人関係など）

### 2. パーソナライゼーション (PersonalizationEngine)

ユーザーの好みに応じて応答スタイルを調整します。

#### パーソナリティプロファイル：
- **formality**: フォーマル度（0: カジュアル、1: フォーマル）
- **emotiveness**: 感情表現度（0: 控えめ、1: 感情豊か）
- **verbosity**: 詳細度（0: 簡潔、1: 詳細）
- **technicality**: 技術レベル（0: 初心者向け、1: 専門的）
- **humor**: ユーモア度（0: 真面目、1: ユーモラス）

#### 応答スタイルの要素：
- 絵文字の使用頻度
- 敬語の使用
- 文末表現のバリエーション
- 挨拶のスタイル
- 説明の深さ

### 3. 文脈分析 (ContextAnalyzer)

会話の内容を深く分析し、適切な応答を生成するための情報を提供します。

#### 分析項目：
- **感情分析**: ポジティブ/ネガティブ/ニュートラルの判定
- **感情の詳細**: 喜び、悲しみ、怒り、恐れ、驚きの度合い
- **トピック抽出**: メイントピックとサブトピックの特定
- **エンティティ認識**: 人名、場所などの固有表現を抽出
- **質問タイプ**: what/why/how/when/where/who/yes-noの分類
- **重要度判定**: 応答の優先度を決定

## 設定方法

`config.toml`で以下の設定が可能です：

```toml
[gemini.chat]
enableMemory = true           # 長期記憶機能の有効/無効
enablePersonalization = true  # パーソナライゼーション機能の有効/無効
```

## 使用例

### 記憶機能の例：
```
ユーザー: 私の名前は太郎です。プログラミングが好きで、特にTypeScriptが得意です。
藍: 太郎さん、はじめまして！TypeScriptがお得意なんですね。（この情報を記憶）

（後日）
ユーザー: 新しいプロジェクトを始めようと思うんだ
藍: 太郎さんの得意なTypeScriptを使ったプロジェクトですか？
```

### パーソナライゼーションの例：
```
ユーザー: もっと詳しく説明して
藍: （説明の深さの好みを学習し、今後は詳細な説明を提供）

ユーザー: 絵文字使わないで
藍: （絵文字の使用を控えるよう学習）
```

## 技術仕様

### データ構造

#### UserMemory
```typescript
{
  userId: string;
  topic: string;
  content: string;
  importance: number;      // 0-1の重要度スコア
  createdAt: number;
  lastAccessedAt: number;
  accessCount: number;
  tags: string[];
}
```

#### UserPreference
```typescript
{
  userId: string;
  category: string;
  preference: string;
  confidence: number;      // 0-1の確信度
  updatedAt: number;
  evidenceCount: number;
}
```

#### ConversationTopic
```typescript
{
  userId: string;
  topicId: string;
  topic: string;
  keywords: string[];
  startedAt: number;
  lastActiveAt: number;
  messageCount: number;
  sentiment: 'positive' | 'neutral' | 'negative';
}
```

## パフォーマンス考慮事項

- 記憶はユーザーごとに最大1000件まで保存
- 古い記憶は重要度とアクセス頻度に基づいて自動削除
- 記憶の検索は最大5件まで取得
- トピックは30分以内のものをアクティブとして扱う

## 今後の拡張予定

- ベクトル検索による、より高度な記憶検索
- 感情の時系列分析
- ユーザー間の関係性グラフ
- より高度な自然言語処理による情報抽出
