### Issue #198: URLの解釈をGemini API依存にする
**概要**: URLプレビュー機能をMisskeyの`/url`エンドポイントからGemini APIのURL Context機能に移行

**変更内容**:
1. `src/modules/aichat/index.ts`の`genTextByGemini`関数を修正
   - Misskey URLプレビューAPI (`urlToJson`) の使用を削除
   - Gemini URL Context機能を実装
   - URLをコレクションに収集し、Gemini APIのtoolsに`url_context`を追加
   - URL Context使用時のシステムインストラクションを追加
   - レスポンスにURL Context metadataの処理を追加

**技術詳細**:
- URL Context機能は最大20個のURLを処理可能
- URLの内容はGemini APIが直接取得・解析
- 成功/失敗したURLの情報をレスポンスに含める
- YouTubeのURLは従来通り特別処理（fileDataとして処理）

### Issue #186: 自動投稿の天気のメッセージ修正
**概要**: 天気予報の自動投稿で「今日の天気」と固定されていた部分を、実際の日付（今日/明日/明後日）に合わせて表示するよう修正

**変更内容**:
1. `src/modules/weather/index.ts`の`formatWeatherToMfm`関数を修正
   - ハードコードされた「今日の天気は」を`${info.dateLabel}の天気は`に変更
   - これにより「明日の天気」「明後日の天気」なども正しく表示されるように

**修正前**: 
```
福井県の明日の天気
---
今日の天気は「晴れ」みたいですよ！
```

**修正後**:
```
福井県の明日の天気
---
明日の天気は「晴れ」みたいですよ！
```

### Issue #189: imagenのTokenについて（aichatと共有化）
**概要**: imagen機能のAPIキーをaichat（Gemini）のAPIキーと共有できるように実装

**変更内容**:
1. `src/modules/imagen/index.ts`を修正
   - `install`関数: imagen.apiKeyがない場合、gemini.apiKeyをフォールバック
   - `generateImage`関数: 同様のフォールバック処理を追加
   - `mentionHook`関数: 同様のフォールバック処理を追加

**利点**:
- 同じGoogle AI APIキーを使用するため、設定が簡素化
- imagen.apiKeyを省略してもgemini.apiKeyがあれば動作
- 既存の設定との後方互換性を維持
