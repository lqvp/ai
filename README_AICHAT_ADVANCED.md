# AIチャット高度拡張機能

このドキュメントでは、藍のAIチャットモジュールに追加された高度な拡張機能について説明します。

## 概要

AIチャットモジュールは、LangChainとGemini APIを活用して、より自然で知的な会話を実現する高度な機能を提供します。

### 主な機能

1. **LLMベース統合分析** - 会話の感情、意図、トピックをLLMが総合的に分析
2. **スマートメモリシステム** - LLMが重要度を判断し、関連性の高い記憶を自動管理
3. **ベクトル検索メモリ** - セマンティック検索による高度な記憶検索
4. **適応的パーソナライゼーション** - ユーザーの性格と好みを学習し、応答スタイルを最適化
5. **会話フロー管理** - 文脈を維持し、話題の転換を検出、一貫性のある応答を生成

## 各コンポーネントの詳細

### 1. LLMAnalyzer（統合分析エンジン）

Gemini APIを使用して会話を多角的に分析します。

#### 分析項目

- **感情分析**: ポジティブ/ネガティブ/ニュートラルと詳細な感情（喜び、悲しみ、怒り、恐れ、驚き、愛）
- **トピック抽出**: メイントピック、サブトピック、キーワード、エンティティ認識
- **意図分類**: 質問、陳述、リクエスト、挨拶、別れなど
- **記憶判定**: 保存すべきか、重要度、カテゴリ、要約
- **パーソナライゼーション提案**: 好みのスタイルと推奨される調整
- **応答ガイダンス**: トーン、長さ、絵文字使用、重点ポイント

### 2. SmartMemoryManager（スマートメモリシステム）

LLMを活用した高度な記憶管理システムです。

#### 主な機能

- **自動記憶保存**: LLMが重要と判断した情報のみを保存
- **関連記憶検索**: LLMが文脈に基づいて最も関連性の高い記憶を取得
- **記憶の要約**: 古い記憶を自動的に要約して効率的に管理
- **動的カテゴリ分類**: LLMが内容に応じて適切なカテゴリを判断
- **プロファイル生成**: 記憶から総合的なユーザープロファイルを生成

### 3. VectorMemoryManager（ベクトル検索メモリ）

LangChainとChromaDBを使用したセマンティック検索ベースの記憶システムです。

#### 主な機能

- **セマンティック検索**: 意味的な類似性に基づく記憶検索
- **クエリ拡張**: 文脈を考慮したクエリの自動拡張
- **記憶のランキング**: 重要度、時間、関連性を考慮したスコアリング
- **記憶の統合**: 古い記憶を要約して新しい記憶として保存
- **拡張サマリー生成**: 文脈を含めた詳細なサマリー

### 4. AdaptivePersonalization（適応的パーソナライゼーション）

ユーザーの性格と好みを学習し、最適な応答スタイルを提供します。

#### ビッグファイブ性格特性

- **開放性（Openness）**: 新しい経験への開放性
- **誠実性（Conscientiousness）**: 計画性と詳細への注意
- **外向性（Extraversion）**: 社交性とエネルギー
- **協調性（Agreeableness）**: 協力性と思いやり
- **神経症傾向（Neuroticism）**: 感情的な安定性

#### コミュニケーション好み

- **応答の長さ**: 簡潔/標準/詳細/適応的
- **フォーマル度**: 0.0-1.0のスケール
- **感情表現**: 0.0-1.0のスケール
- **ユーモアレベル**: 0.0-1.0のスケール
- **技術的深さ**: 0.0-1.0のスケール
- **創造性レベル**: 0.0-1.0のスケール

### 5. ConversationManager（会話フロー管理）

会話の流れと文脈を管理し、一貫性のある応答を実現します。

#### 主な機能

- **会話状態の追跡**: トピック履歴、感情の変化、重要ポイント
- **話題転換の検出**: スムーズな話題転換のサポート
- **未解決質問の管理**: 質問への回答状況を追跡
- **応答の一貫性チェック**: 文脈に合った応答かを検証
- **応答の強化**: 文脈を考慮した応答の改善

## 使用方法

### 設定

`example.config.toml`で以下の設定を行います：

```toml
[gemini.chat]
enabled = true
enableMemory = true # 記憶機能の有効/無効
enablePersonalization = true # パーソナライゼーション機能の有効/無効
```

### データフロー

1. **ユーザーメッセージ受信**
   - ConversationManagerが会話を開始/継続
   - LLMAnalyzerが会話を分析

2. **コンテキスト構築**
   - VectorMemoryManagerがセマンティック検索で関連記憶を取得
   - SmartMemoryManagerが文脈に基づいた記憶を取得
   - ConversationManagerが会話の文脈を提供

3. **パーソナライゼーション**
   - AdaptivePersonalizationがユーザープロファイルを基にプロンプトを生成
   - 応答スタイルの推奨を提供

4. **応答生成**
   - Gemini APIが拡張されたプロンプトで応答を生成
   - ConversationManagerが応答の一貫性をチェック・強化

5. **事後処理**
   - 記憶の保存（スマートメモリ、ベクトルメモリ）
   - パーソナライゼーションの更新
   - 会話状態の更新

## 高度な機能

### 記憶の統合

古い記憶を定期的に要約・統合することで、効率的な記憶管理を実現：

```typescript
// 30日以上前の記憶を自動的に要約
await vectorMemoryManager.consolidateMemories(userId);
```

### 動的プロンプト生成

ユーザーの性格、現在の文脈、時間帯などを考慮した動的なプロンプト生成：

```typescript
const prompt = await personalization.generatePersonalizedPrompt(
  userId,
  basePrompt,
  {
    currentMood: 'happy',
    recentTopics: ['技術', 'AI'],
    timeOfDay: '朝'
  }
);
```

### 会話の要約

会話全体を分析し、構造化された要約を生成：

```typescript
const summary = await conversationManager.generateSummary(conversationId);
// {
//   mainTopics: ['AI技術', 'プログラミング'],
//   emotionalJourney: 'curious → excited → satisfied',
//   keyDecisions: ['新しいプロジェクトを開始する'],
//   actionItems: ['ドキュメントを作成する'],
//   unresolvedQuestions: ['実装の詳細について']
// }
```

## パフォーマンス最適化

### 確率的実行

コストを抑えるため、一部の処理は確率的に実行：

- LLM分析: 20%の確率で実行（設定可能）
- 記憶の統合: 5%の確率で実行
- プロファイル更新: リアルタイムで実行（5件以上のインタラクション後）

### キャッシング

- ユーザープロファイルはメモリにキャッシュ
- ベクトル検索結果は一時的にキャッシュ
- 会話状態は24時間保持

## 拡張性

### カスタムアナライザー

独自の分析項目を追加可能：

```typescript
// LLMAnalyzerのプロンプトをカスタマイズ
const customAnalysis = await analyzer.analyzeConversation(message, {
  customPrompt: '専門用語の使用頻度も分析してください'
});
```

### プラグイン対応

各コンポーネントは独立しているため、必要に応じて個別に使用可能：

```typescript
// ベクトルメモリのみを使用
const memories = await vectorMemoryManager.getSemanticMemories(
  userId,
  query,
  10
);
```

## トラブルシューティング

### ChromaDBへの接続エラー

```
Failed to initialize vector store: Error: connect ECONNREFUSED
```

解決方法：
- ChromaDBが起動していることを確認
- フォールバックとしてインメモリストアを使用

### LLM分析のタイムアウト

```
Failed to analyze conversation: timeout
```

解決方法：
- タイムアウト値を増やす
- 分析の実行確率を下げる

### メモリ使用量の増加

解決方法：
- 会話履歴の保持数を減らす
- 古い会話を定期的にクリーンアップ
- 記憶の統合頻度を上げる
